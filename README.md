Toy shell project
# Features
* No dependencies except libc
* Pipe support (command chaining)
* I/O Redirection (input, output and append file redirection)

## Credits
Idea: One of my college friends who thought it would be cool

Rest: me

# Requirements
* A true colour terminal for proper colours. The prompt cannot be changed unless
you recompile and I'm going to try and make it so you can't change the prompt
from a hot pink colour.

# Compiling
Compile it with:
```bash
cc src/main.c
```
You can run it like so:
```
./a.out
```
